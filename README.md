# Self-Tested-Smart-ALU-with-BIST-and-UART-Reporting-Low-Power-VLSI-Design
This project presents a 4-bit Arithmetic Logic Unit (ALU) with an integrated Built-In Self-Test (BIST) architecture, designed for low-power and fault-tolerant VLSI applications. It features real-time UART-based status reporting and LED indication, providing both automation and observability for system diagnostics.
